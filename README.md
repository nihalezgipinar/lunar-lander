# Lunar Lander

A physics-based lunar lander built in Unity (C#).

- Rigidbody-driven thrust and rotation, with fuel burn tied to input
- Landing detection that distinguishes a safe touchdown from a crash by
  contact velocity and orientation
- Scoring loop with restart

**Engine:** Unity · **Language:** C#

`Library/` is Unity build cache and is intentionally not tracked; Unity
regenerates it on first open.
